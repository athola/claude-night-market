# Makefile Review Command

Audit Makefiles for best practices and portability.

## Usage

```bash
/makefile-review
```

## What It Does

Invoke `Skill(pensive:unified-review)` in its makefile focus, the same as
`/full-review makefile`. Its `modules/makefile-review.md` carries the audit
workflow, the portability checks and the output format.
