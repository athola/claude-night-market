## Summary

# SingleFile: single-file HTML web page archiver

SingleFile archives complete web pages into one self-contained HTML file with no external dependencies. Browser extension plus a CLI for programmatic capture; minification, annotation, multiple output formats, auto-save and batch operations, and an integration ecosystem. Reference for offline-accessible page snapshots in PKM/research workflows.

## Key points

- Saves a complete page (HTML/CSS/images) into one self-contained HTML file
- Web extension for Chrome/Firefox/Safari/Edge, plus a single-file CLI
