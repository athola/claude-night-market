# StepSnap (OpenScribe): screen-interaction to step-by-step guide recorder

StepSnap records mouse/keyboard/screenshot interactions and turns them into editable, reorderable, exportable (PDF/DOCX) step-by-step guides. Built on Tauri 2 with a React/TS frontend and Rust backend, cross-platform. Reference for automated procedural-documentation systems that capture tacit 'how-to' steps from real usage.
