# Tacit Knowledge Extraction via Logic-Augmented Generation and Active Inference (Lamazzi et al.)

Lamazzi et al. propose a neuro-symbolic pipeline (Logic-Augmented Generation + active inference) to extract tacit, process-centric knowledge from instructional videos into ontology-grounded, queryable Knowledge Graphs, validated on manufacturing repair. Enables formal machine-interpretable capture of implicit procedural expertise.

## Key points

- Neuro-symbolic framework: Logic-Augmented Generation + active-inference methods
- Ontology-grounded Knowledge Graph construction from process-centric knowledge
- Extracts procedural knowledge from assembly/repair instructional videos
- Captures implicit assumptions, constraints, experience-based judgments
- Validated on manufacturing repair procedures as a reproducible proxy
