# Memos: self-hosted Markdown note-taking with instant capture

Memos is a self-hosted, lightweight Markdown note app with a timeline-first capture UI, single Go binary deployment, portable Markdown storage, and REST/gRPC APIs. Production-grade reference for self-hosted capture architecture prioritizing data ownership and simplicity.

## Key points

- Single ~20MB Go binary; SQLite/MySQL/PostgreSQL backends, one-command deploy
- Timeline-first UI for rapid capture without folder navigation
- Portable Markdown storage, zero telemetry, no cloud requirement
- REST + gRPC APIs for third-party integration; Docker/native/Helm deploy
- MIT-licensed, production-grade example of lightweight self-hosted PKM
