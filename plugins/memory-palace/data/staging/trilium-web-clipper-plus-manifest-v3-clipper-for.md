# Trilium Web Clipper Plus: Manifest V3 clipper for Trilium Notes

Trilium Web Clipper Plus is a Manifest V3 Chrome extension clipping text, pages, and screenshots into Trilium Notes with keyboard shortcuts, auto-clip, and i18n. A modernized fork. Reference for MV3-compliant clipping with server synchronization patterns.

## Key points

- Chrome Manifest V3 clipper (V2-deprecation successor to zadam/trilium-web-clipper)
- Modes: selected text, full page, screenshot, quick note
- Keyboard shortcuts for rapid clipping; configurable auto-clip with source URL
- i18n framework for multi-language UI
- ~94% JavaScript; talks to a Trilium server backend
