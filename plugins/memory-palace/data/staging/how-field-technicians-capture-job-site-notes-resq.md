# How Field Technicians Capture Job-Site Notes (ResQ Nora)

Survey of how field technicians capture notes today: low-friction voice/text/photo/video intake, auto-transcription and tagging, geotagging, offline-first sync, conditional-logic checklists, and automatic routing to back-office systems. Reference for field-notes capture tooling design.

## Key points

- Voice/text/photo/video sent to platform, no new UI to learn
- Voice transcribed and auto-tagged with job numbers and keywords
- Geotagged photos/videos document site conditions and completed work
- Offline-first capture syncing when connectivity returns
- Conditional-logic forms; auto-routing of notes to office/invoicing
