# Web Clipper: multi-platform browser capture to 20+ note apps

Web Clipper is a Chrome/Edge extension that captures pages and routes them to 20+ note platforms (Notion, Obsidian, Joplin, Confluence, etc.), using readability extraction and a normalization pipeline across heterogeneous destination APIs. Reference for unified multi-destination capture abstracting platform formatting differences.

## Key points

- Chrome/Edge extension routing captured content to 20+ destinations
- Targets Notion, OneNote, Bear, Obsidian, GitHub, Joplin, Confluence, Yuque
- TypeScript (96.7%), webpack, Vitest
- Readability extraction + per-destination formatting normalization
- Abstracts platform-specific formatting behind one capture workflow
